Static one-page site for WHCBB / WORK.

## GitHub Pages

1. Upload `index.html`, `styles.css`, `script.js`, and `CNAME` to the root of the `main` branch.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**.
4. GitHub should detect `whcbb.work` from the CNAME file.
5. Point the domain DNS to GitHub Pages, then enable **Enforce HTTPS** when available.
